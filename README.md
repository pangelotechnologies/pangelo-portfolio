# PANGELO Portfolio

Single-page static portfolio for PANGELO. No build step required.

## Deploy to Vercel
1. Put `index.html`, `style.css`, and `script.js` in a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other** (or leave auto-detected).
4. Build command: leave blank.
5. Output directory: leave blank / root.
6. Deploy.

The portfolio is intentionally static, so the free Vercel plan is sufficient.

## Customize
- Replace `hello@pangelo.com` with your real email address.
- Update project links/descriptions in `index.html`.
- Replace the visual gradient cards with real project screenshots later if desired.
